# AI Laboratory Programs

This repository contains the AI lab experiment implementations extracted from the course lab sheet.

## Experiments

| File | Description |
|---|---|
| [`exp1.py`](exp1.py) | Map Coloring Problem using Constraint Satisfaction Problem (CSP) / Backtracking |
| [`exp2.py`](exp2.py) | Farmer, Wolf, Goat, and Cabbage Puzzle using Logical Programming / DFS Search |
| [`exp3.py`](exp3.py) | Sudoku Generation using Genetic Algorithm (Metaheuristic Search) |
| [`exp4.py`](exp4.py) | Traffic Assistance and Route Recommendations Bot |
| [`exp5.py`](exp5.py) | Disease Diagnosis using Inference Rules |
| [`exp6.py`](exp6.py) | Predicting Student Course Success using Bayesian Network |
